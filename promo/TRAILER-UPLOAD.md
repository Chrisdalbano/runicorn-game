# Description

Bad wish. Good problem.

Draw rainbow loops. Trap the undead herd. Make every catch sing.

Runicorn Zombie Apocalypse is a tiny browser roguelike with five districts, strange upgrades, and one last wish. Aim the Megacorn blaster, dash with the Requiem Gun, or find the rare Nyan-Unicorn and leave a denser rainbow behind you.

```yaml

---
```

Replace the placeholder with the published URL before committing. Preserve any other frontmatter. The repository's example documents this field: https://github.com/js13kGames/hello-world/blob/main/README.md
